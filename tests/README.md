# Full Practice Tests

This folder contains complete IELTS practice tests scraped from third-party sources.

## Structure

```
tests/
  academic/
    test-1/
      reading/       # 3 passages + questions + answers
      listening/     # 4 sections + questions + answers + transcripts
      writing/       # task-1.md + task-2.md
      speaking/      # part-1.md + part-2.md + part-3.md
  general-training/
    test-1/
      reading/       # 3 sections + questions + answers
      listening/     # same as academic (same test)
      writing/       # task-1.md (letter) + task-2.md (essay)
```

## Sources
- ieltsonlinetests.com — 120+ full mock tests
- examenglish.com — free, no account required
- ielts-mentor.com — free with model answers
